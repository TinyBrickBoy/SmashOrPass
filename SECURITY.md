# Security Policy

Smash or Pass can archive and delete GitHub repositories, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Instead, use GitHub's [private vulnerability reporting](https://github.com/TinyBrickBoy/SmashOrPass/security/advisories/new) for this repository.

Please include:

- a description of the issue and its impact
- steps to reproduce
- affected version or commit

You will get a response as soon as possible. Once the issue is fixed, you will be credited in the release notes if you like.

## Supported versions

Only the latest version on the default branch receives security fixes.
